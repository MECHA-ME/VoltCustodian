⚡ VoltCustodian
IoT-Enabled Smart BS6 Vehicle Battery Charging & Power Management System

📌 Overview
VoltCustodian is an SMPS-based smart battery charging and monitoring system designed for BS6 vehicle batteries.
It replaces conventional uncontrolled chargers with a regulated, sensor-driven, and IoT-enabled charging solution that ensures safety, efficiency, and battery longevity.

The system integrates real-time sensing, embedded control logic, and remote monitoring to provide controlled charging and battery diagnostics for workshops, fleet operators, and educational institutions.

🎯 Problem Statement
Traditional vehicle battery chargers:
Lack real-time monitoring
Offer poor voltage/current regulation
Increase risk of overcharging and overheating
Reduce battery lifespan
Provide no remote diagnostics
VoltCustodian addresses these limitations with intelligent control and monitoring.

🚀 Key Features
Regulated AC–DC SMPS power conversion
CC–CV (Constant Current – Constant Voltage) charging algorithm
Real-time voltage, current, and temperature monitoring
Over-voltage, over-current, short-circuit, and thermal protection
IoT-based remote monitoring via mobile/web dashboard
Data logging and charging analytics
Modular and scalable design

🏗 System Architecture
Power Conditioning Unit – SMPS-based AC–DC regulated conversion
Smart Control Unit – Microcontroller executing charging logic
Sensor Layer – Voltage, current, and temperature monitoring
Communication Layer – Wi-Fi/GSM for cloud connectivity
User Interface – Mobile app & web dashboard
Battery Interface – Controlled and protected energy delivery
